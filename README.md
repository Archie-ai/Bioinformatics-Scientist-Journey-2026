# Bioinformatics-Scientist-Journey-2026
## About This Repository

This repository documents my professional development in bioinformatics,
computational genomics, NGS analysis, reproducible workflows, and clinical
bioinformatics.

The goal of this four-month program is to strengthen my practical,
software-engineering, computational, and clinical bioinformatics skills through
hands-on projects and documented learning.

## Background

I am an M.S. Bioinformatics student with a background in biotechnology,
molecular biology, computational biology, and biomedical research.
